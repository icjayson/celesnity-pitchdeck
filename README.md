# Celesnity Landing Decks

This project holds the interactive landing decks Celesnity sends to clients.

Each client gets a private web page that tells the Celesnity story in their own context: what a smart factory could look like for them, how it would roll out, and what it would deliver. Visitors can explore interactive sections, open an appendix, print a full version, or ask questions to a built-in AI assistant that knows only that client's deck.

Current decks include Hòa Phát, Nestlé, Isuzu, Takako, SCG and a pilot report for Saigon Food. The home page is a portal that helps investors and buyers find the right deck.
