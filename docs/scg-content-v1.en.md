## `#ba-lop`

### The World Model forecasts and recommends; people, machines, software and robots carry it out; Minder records; authorised people approve

*How the Super-Smart Factory works*

<!-- module M7 -->

**Improvement loop:** approved decisions, commands sent to the machine and actual results flow back to layer ①, and the model keeps learning.

**What only a World Model can do:** the control system and sensors record what happened. Minder also records **who decided what, why, and what happened next**. By learning from thousands of "setpoint → kiln response → clinker quality" sequences, the model understands **consequences**, like an experienced kiln engineer who never goes off shift.

**A World Model is not:**

`A chatbot` · `Enterprise resource planning software` · `A video generation model` · `A replacement for the control system or the safety system` · `Something that changes setpoints without anyone approving` · `A replacement for process simulation (thermal, combustion and gas flow simulation is still done by engineers, and the results feed the model)`

#### How the layers work together

| Layer | Role | What it does |
|---|---|---|
| **① World Model**: "the brain that understands the plant" | Forecast | Learns how the kiln, the mills and the whole plant respond to decisions; forecasts with a level of confidence; says "I don't know" when it meets a situation with no data, and never makes up a result |
| **② Minder**: "the plant's memory" | Record | Reads machine signals · records work by voice in Vietnamese and Thai · connects to existing systems · manages permissions · keeps every decision and every command |
| **Authorised people** | Decide | Approve every command sent to the machine, set setpoint limits, make quality and dispatch decisions |

### The Model reads data from the machine and, through Minder, sends commands back for the machine to act on

*Demo · from machine data to machine command*

*[ai] A real demo in Celesnity's laboratory: an industrial robot, a camera and a Minder device at the machine. Not a Siam Cement Group plant.*

[Video: Minder Hub controlling a robot cell](/decks/scg-vietnam/demo-dieu-khien-may-phu-de.mp4) — The camera reads the position of each part on the tray · the Minder device at the machine connects the robot and camera · Minder Hub reports status and sends the cycle-start command · the robot carries it out and reports completion

| Step | What happens in the demo | At a Siam Cement Group kiln |
|---|---|---|
| **Read** | The camera and robot controller report status to the Minder device at the machine: gateway online, robot connected, camera running. | Minder at the machine reads control system signals: burning zone temperature, O₂, pressure, kiln torque, feed, fuel. |
| **Understand** | The position and orientation of each part are calculated and become targets for the robot. | The Model forecasts where the kiln is heading over the next 1–2 hours and compares setpoint options. |
| **Approve and send** | The operator presses "Start cycle" in Minder Hub; the command goes to the robot. | The shift lead approves the recommendation; Minder writes the setpoint to the control system, only within the limits approved by Process. |
| **Act and report back** | The robot picks each part; the status changes to "running", then "complete". | The control system executes; Minder reads back the kiln's response and the laboratory results, compares them with the forecast, and the model keeps learning. |

> The same **read → understand → approve → act → verify** loop applies to every type of machine. The plant's interlocks, safety systems and emergency stop always override any Minder command.

#### Three levels of autonomy; Siam Cement Group decides when to move up

|  |  |
|---|---|
| **Level 1 · Advisory** | The Model recommends, with a forecast and evidence; operators adjust the control system themselves, as today. Every time a recommendation is not followed, the reason is recorded. |
| **Level 2 · With approval** | An authorised person approves a recommendation; Minder writes the setpoint to the control system within the approved range, then reports the result. |
| **Level 3 · Automatic within limits** | Only for setpoints and narrow ranges Siam Cement Group has approved after months at level 2; operators can still switch it off at any time. |

# `/phu-luc`

## How the World Model works (simplified)

1. **Record:** everything at the plant becomes a "state → decision → outcome" sequence (for example: kiln state → setpoint change → kiln response and free lime).
2. **Learn:** the model learns patterns of the form "doing X in state Y usually leads to Z".
3. **Forecast with a level of confidence:** the model says "I don't know" when it meets raw materials, fuels or operating modes it has never seen.
4. **Separate cause from coincidence:** operators usually change setpoints for a reason, so the model uses statistical methods to separate the true effect from the reason for the choice. When the data is not enough to tell them apart, the model says so.
5. **Check technical limits:** a separate checking layer ensures recommendations stay within setpoint ranges, equipment limits and environmental regulations.
6. **No experiments on the kiln:** the model learns only from recorded operation and approved changes.

*Technical detail for the engineering team:*

- The model core learns in a representation space (a JEPA-style approach).
- Confidence is calibrated with conformal methods.
- Effects are estimated with propensity and doubly robust methods.
- Training and testing are split by time.
- Minder at the machine: reads via OPC UA or Modbus from the control system and programmable logic controllers; writes setpoints only through an approved gateway, within limits, with a log and read-back confirmation.

## Risks and mitigation

| Risk | Mitigation |
|---|---|
| Kiln data is insufficient or poorly time-aligned | Gate 1 checks this first; start with available data, add sensors only where needed |
| The model does not beat the current approach | Gate 2 with a blind test set; if not passed, stop, with no move to a paid phase |
| Commands written to the machine create operating risk | Opened only after Gate 2; setpoint by setpoint; narrow ranges approved by Process; a person approves each time; interlocks and safety systems always override |
| Experience from one plant does not transfer to the next | Each new plant has its own survey and test set; what carries over is the platform, the method and the team, with no assumption that accuracy carries over |
| Data leaves the country | A separate environment at each plant, within its own jurisdiction; only tested weights approved by Siam Cement Group are shared |
| Dependence on Celesnity | Plant engineers master the new way of operating from the first months; source code and models are held in escrow |
| Workers worry about being monitored | Prior consultation; de-identification; never used to assess individuals |
